Как мозг мухи играет в тетрис

Поле кодируется как зрительный вход. Сигнал проходит по реальному мотиву MaleCNS (R1–R6 → … → DNg13 → VNC). Descending neurons «решают» сдвиг, поворот и дроп.

Играть
фото→ lam→ med→ lob→ VPN→ центр→ DN→ VNC→ act

1–4 · Зрительные доли

Фоторецепторы R1–R6 → ламина (L1–L3) → медулла (Mi1/Tm) → lobula / lobula plate. Здесь формируется «картинка» стека и фигуры.

optic lobe · слои lam→med→lob→LP

5–6 · VPN и центр

Visual projection neurons (LoVP92 и др.) несут объектный сигнал в AOTU / LAL / VES. Центральный мозг интегрирует L/R и готовит руление.

LoVP92 → CB0244 / LAL · VES200m ⊣ DNg13

7–9 · DN → VNC → ход

DNg13 L/R сдвигают, DNa02 крутит, интернейроны VNC (IN17A025) дропают. Стадия «act» — видимый ход на доске.

descending · neck connective · VNC T1–T3

Фильтр стадий

Клик по стадии в конвейере подсвечивает только её узлы, связи, частицы и строки растра. «Все» сбрасывает.

Нейропиль 3D

Объёмные оболочки optic / central / DN / VNC с нейронами внутри. След решения при ходе мозга · режим «Только активные».

Каталоги

Клик / тултип узла открывает Cell Type Explorer и поиск Codex / FlyWire по имени типа.
